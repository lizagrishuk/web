## Функционал реализован

- Динамическое отображение прогноза погоды на **сегодня** и на **2 следующих дня**  
- Получение погоды для **текущего местоположения** с помощью геолокации  
- Возможность **вводить город вручную**, если геолокация недоступна  
- **Добавление как минимум двух дополнительных городов** для отображения погоды  
- **Переключение между городами**  
- Кнопка **«Обновить»** для повторного запроса данных без перезагрузки страницы  
- **Автодополнение** при вводе города с валидацией  
- Сохранение состояния города и выбранной локации через **localStorage**  
- Поддержка **клавиатуры (ПК)** и кнопок/свайпов (мобильные устройства)  
- Адаптивный дизайн для разных экранов  
- Цветовое различие плиток и плавная анимация отображения погоды  

---

## Технические детали

- Использован **чистый HTML, CSS и JavaScript**  
- Игровое поле и элементы создаются **динамически через JS**  
- Обработка ошибок и состояния загрузки (успех/ошибка/загрузка)  
- Сохранение всех пользовательских данных через **localStorage**  
- Реализованы кнопки управления: «Добавить город», «Обновить», переключение между городами  

---

## Особенности реализации

- Прогноз погоды обновляется без перезагрузки страницы  
- Состояние приложения сохраняется при закрытии и повторном открытии  
- Автодополнение городов с выпадающим списком  
- Адаптивный интерфейс корректно отображается на мобильных и десктопных устройствах  
- Красивое визуальное оформление, плавные анимации и цветовое выделение погодных данных
