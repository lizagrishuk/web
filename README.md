# ToDo App. Грищук Елизавета

## Описание проекта
Простое веб-приложение ToDo-лист на чистом JavaScript.  
Пользователь может создавать, редактировать, удалять задачи, отмечать их как выполненные, фильтровать, сортировать, искать по названию и менять порядок задач с помощью drag-and-drop.  

## Что выполнено
- Создана семантическая HTML-структура через JavaScript.
- Добавление новой задачи.
- Удаление задачи из списка.
- Редактирование текста задачи.
- Отметка выполненной задачи с визуальным оформлением.
- Сортировка задач по дате.
- Фильтрация по статусу: выполненные / невыполненные / все.
- Поиск задач по названию.
- Сохранение задач в localStorage и восстановление при загрузке страницы.
- Drag-and-drop для изменения порядка задач.

## Технологии
- HTML (только базовый каркас)
- CSS (адаптивность через flex/grid)
- JavaScript (DOM API, LocalStorage, drag-and-drop)
