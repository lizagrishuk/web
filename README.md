# Игра 2048

**Функционал реализован:**
- Динамическое игровое поле 4x4 с плитками
- Движение плиток во всех направлениях с объединением одинаковых чисел
- Генерация новых плиток (2 или 4) в случайных пустых клетках
- Подсчет очков и отображение текущего счета
- Кнопки: **Начать заново**, **Отмена хода**, **Таблица рекордов**
- Таблица лидеров (топ-10) с именем, очками и датой
- Сохранение состояния игры и лидерборда в `localStorage`
- Управление с клавиатуры (ПК) и кнопок/свайпов (мобильные устройства)
- Адаптивный дизайн для разных экранов
- Цветовое различие плиток и плавная анимация слияния

**Технические детали:**
- Использован чистый HTML, CSS и JavaScript
- Игровое поле и плитки создаются динамически через JS
- История ходов для функции undo хранится в массиве и в `localStorage`
- Лидерборд обновляется и сортируется по очкам

**Особенности реализации:**
- Возможность отменить последний ход (кроме завершения игры)
- Состояние игры сохраняется при закрытии и повторном открытии страницы
- Мобильные устройства поддерживают управление через виртуальные кнопки или свайпы
- Визуальное оформление плиток соответствует стандарту 2048 (цвета и размеры)
